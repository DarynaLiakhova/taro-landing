# Путь Таролога: лендинг

Одностраничный лендинг курса Таро Лены (Ellene Del Sol’). Кнопки ведут на платформу: https://darynaliakhova.github.io/taro-platform/

Статичная страница без сборки: `index.html` и папка `assets`. Публикуется через GitHub Pages (ветка main, корень).

## Тесты

Автотесты на Playwright проверяют лендинг на четырёх экранах: ноутбук 1366, монитор 1920, телефон 390 и маленький телефон 360.

Первый запуск:
```
npm install
npx playwright install chromium
```

Проверить всё: `npm test`. Отчёт с скриншотами упавших проверок: `npm run test:report`.

Что проверяется:
- страница без ошибок, все картинки грузятся, нет прокрутки вбок, все ссылки-якоря ведут на разделы, порядок блоков;
- компьютер: заголовок на табличке в две строки и не наезжает на подзаголовок, табличка и плитки в первом экране, плитки и ступени работают;
- телефон: вертикальный первый экран, плашка и ссылки разделов помещаются, бургер, карты ступеней переворачиваются, купить можно только I ступень, шторка с лекциями.
